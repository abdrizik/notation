# notation

hand-drawn annotations for the web. Zero dependencies.

Underlines, boxes, circles, highlights, strike-throughs, cross-offs, brackets and arrows, or a shape you write yourself, drawn as animated SVG strokes.

[Documentation](https://notation.shardsui.com)

## Install

```sh
npm i @shardsui/notation
```

## Usage

```js
import { annotate } from '@shardsui/notation'

annotate('#title', { type: 'underline' }).show()
```

## Browser support

Chrome and Edge 113, Firefox 115, and Safari 17.4 or later.
